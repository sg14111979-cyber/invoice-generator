Restoring replaces everything currently in the app with the contents of the backup file.

How to use

  1. My business — type your business name, address, phone, GST number, bank details and upload your logo. You only do this once; it appears on every invoice. Running two businesses? Click "Add another business" and switch them from the box at the top right.
  2. Customers — add the people you bill. Then you can pick them on an invoice instead of typing the address every time.
  3. Items — save each product or service once with your own code (like A4-COPY-80), a name and a rate. On an invoice, type that code or name in the Code box and the description and rate fill themselves in, so the same thing is billed identically to every customer. Typed a line by hand? Press Save on that line to add it to the list.
  4. Make invoice — the number and date fill themselves in. Pick the customer, add one line per product or service, and watch the invoice on the right build itself.
  5. Tax, discount, shipping — choose no tax, one tax rate, or GST (same state gives CGST + SGST, other state gives IGST). Discounts can be a percent or a flat amount. Everything is totalled for you.
  6. Save invoice — keeps it under "Saved invoices", where you can search, reopen, duplicate or delete it.
  7. Print / Save as PDF — opens the print window. Pick "Save as PDF" as the printer to get a file you can email or send on WhatsApp; pick your printer for paper.
  8. Backup — download a backup file once in a while. If you change computer or browser, restore that file there.

Good to know

  • No internet, no installation and no account needed — this single file is the whole app.
  • Your data never leaves your computer. Nothing is uploaded anywhere.
  • Data lives in this browser: use the same browser each time, and don't use private/incognito windows.
  • Changing an item's rate later never changes invoices you already saved — each invoice keeps its own copy.
  • For a quotation or proforma, change "Document title" at the top of the invoice. Duplicate it later to turn it into the real invoice.

INVOICE STUDIO - SIMPLE OFFLINE EDITION
=======================================

Nothing to install. No Node.js, no terminal, no internet needed.

HOW TO START
------------
1. Extract this ZIP (right-click the ZIP -> Extract All...). Do not run it
   from inside the ZIP preview window.
2. Double-click "Invoice Studio.html". It opens in your browser (Chrome or
   Edge work best).
3. That's it. Bookmark the page so you can come back to it quickly.

FIRST TIME (2 minutes)
----------------------
1. Open the "My business" tab. Fill in your business name, address, phone,
   GST/Tax number, bank details and upload your logo. Click Save.
2. Open the "Customers" tab and add the people/companies you bill (optional -
   you can also type customer details straight onto an invoice).
3. Open the "Make invoice" tab.

MAKING AN INVOICE
-----------------
- Pick a customer (or type the name and address).
- Add one line per item: description, quantity, rate. Totals update live on
  the preview on the right.
- Choose the tax: "No tax", "One tax rate", or "GST" (same state gives
  CGST + SGST, other state gives IGST).
- Add discount, shipping and amount paid if needed. Balance due is calculated.
- Click "Save invoice" to keep it in the "Saved invoices" list.

PDF AND PRINTING
----------------
Click "Print / Save as PDF". In the print window choose:
- Destination: "Save as PDF" to get a PDF file, or your printer to print.
- Paper size A4, margins Default, and tick "Background graphics" for colour.

DOCUMENT TYPES
--------------
The "Document title" box lets one invoice form produce an Invoice, Tax
Invoice, Proforma Invoice, Quotation or Receipt.

BACKUPS - PLEASE READ
---------------------
Your data is saved inside this browser on this computer only. It is not in
the cloud. If you clear browser data, change browser or change computer, the
data goes with it.

So once a week: open the "Backup" tab -> "Download backup". Keep that .json
file safe (Google Drive, email to yourself, USB stick). To move to another
computer, copy "Invoice Studio.html" there, open it, then use
"Restore from backup" and pick the .json file.

WHAT ABOUT THE BIGGER VERSION?
------------------------------
This offline edition is for one person on one computer and has no login. The
full Invoice Studio web app in this same repository adds accounts and
passwords, per-user data separation, admin users and a shared database - use
that one if several people need access or if it must run on a server.
